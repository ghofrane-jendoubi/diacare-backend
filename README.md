# 🩺 DiaCare Backend

Backend de la plateforme DiaCare, développé avec Spring Boot, intégrant des services d’intelligence artificielle pour l’analyse du diabète.

---

## 🚀 Description

Ce projet gère la logique métier, la sécurité, les API REST et l’intégration avec les modèles IA (Machine Learning & Deep Learning).

---

## 🎯 Fonctionnalités principales

- 🔐 Authentification & autorisation (JWT)
- 👥 Gestion des utilisateurs (patient, médecin, nutritionniste, admin)
- 📊 Gestion des données médicales
- 📅 Gestion des rendez-vous
- 💬 Chat entre patient et médecin
- 📷 Upload d’images (analyse Deep Learning CNN)
- 🧠 Analyse des données (Machine Learning)
- 🛒 Gestion parapharmacie (produits, commandes)
- 📚 Gestion contenu éducatif
- 📍 Géolocalisation (API Maps)
- 🔔 Notifications

---

## 🛠️ Technologies utilisées

- Java 17
- Spring Boot
- Spring Security
- JWT
- Hibernate / JPA
- MySQL
- REST API
- Flask (microservice IA)
- Python (ML / DL)
- TensorFlow / Keras / YOLO
